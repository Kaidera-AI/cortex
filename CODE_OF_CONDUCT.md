# Code of Conduct

Be professional, be kind, argue about the work and never about the person.

- Harassment, discrimination or personal attacks are not tolerated, anywhere, from anyone.
- Disagreement is welcome when it comes with reasoning and, better, with measurements.
- Maintainers may edit, lock or remove contributions that break this, and repeat or severe
  violations mean removal from the project.

Report conduct issues privately to conduct@kaidera.ai.
