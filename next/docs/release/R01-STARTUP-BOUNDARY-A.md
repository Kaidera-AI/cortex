## Fixed startup contract

The external owner selects one executable and entrypoint, exact interpreter version, explicit ordered import roots and an independently protected empty cache prefix. Its fixed invocation is `<owner executable> -I -S -B -X pycache_prefix=<owner empty cache> <owner entrypoint>`, with a deliberately empty environment. CPython's intrinsic locale/platform additions are tolerated; Python/loader/test-root/other ambient selectors are refused in admitted A. `-I` ignores Python environment and unsafe initial/user paths; `-S` independently disables site/.pth processing; `-B` prevents writes but does not by itself prevent cache reads. This source profile therefore requires the owner-selected empty cache prefix and rejects sourceless loaders. It is a verifier/bootstrap source profile, not a change to Cox's runtime ABI or inspector vectors.

The bootstrap is responsible for setting ONLY the explicit admitted import roots before importing product code. Source checks compare effective flags, executable, entrypoint, version, ordered roots, cache prefix and import machinery; they do not launch a process or repair dependencies. Standard builtin/frozen/PathFinder identity is checked. Path hooks are exact independently held bootstrap objects; custom cached finders/loaders refuse. Loaded file origins must resolve to the owner's original file table; intrinsic names must belong to its admitted interpreter inventory, namespace paths remain within the exact roots, and test support is forbidden even if a bad table names it.

These checks run after trusted bootstrap code has necessarily executed. They cannot attest the code that implements them, protect a writable runtime or discover an exhaustive native dynamic-loader closure. The independent bootstrap must establish that admission before execution. This source layer verifies consistency and drift over those independently supplied originals and current observations. Actual code/root/UID/ACL/mount/launch/import/native closure completeness is NOT_RUN and held for N1/N2/B qualification.
